# Classic Interlude Devlog

The project's public page (GitHub Pages: branch `main`, folder `/docs`).

    python build.py

rebuilds `docs/index.html` from the `dev` branch of the server, client and runtime repos next to this folder and the
feature table of the runtime repo's FEATURE_CHECKLIST.md. E-mail addresses, IPv4 addresses, Windows user folders and
Co-Authored-By lines are removed from every text; commit authors are not shown. Commit and push after each rebuild.

`progress.md` is the systems scorecard behind the overall progress; `highlights.md` holds the hand-written daily highlights.
